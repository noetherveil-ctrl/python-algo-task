# Задачи на Python

## Количество различных чисел

[Условие](https://coderun.yandex.ru/problem/number-different-numbers),
код — `different_numbers.py`.

Читаю строку чисел и собираю из них множество. Повторы в множестве не
сохраняются, поэтому его размер и есть ответ. Например, для `1 2 2 3`
получится `{1, 2, 3}`, то есть ответ 3.

Выбрал множество, потому что здесь нужно только убрать повторы.
Сортировать числа или сравнивать каждое со всеми остальными не требуется.

Для n чисел ожидаемое время — O(n): вставка в множество в среднем
занимает O(1).
Память — O(n), включая чтение и разбиение входной строки.

## Пересечение множеств

[Условие](https://coderun.yandex.ru/problem/intersection-sets),
код — `intersection.py`.

Читаю две строки как два множества. Операция `&` оставляет числа, которые
есть в обоих. Затем сортирую результат и печатаю через пробел. Например,
для `1 3 2 2` и `3 2 4` общие числа — 2 и 3. Если общих чисел нет,
выводится пустая строка.

Множества сразу убирают повторы и позволяют быстро проверять наличие числа.
Сортировка нужна только для общих элементов, потому что ответ должен идти
по возрастанию.

Пусть в строках n и m чисел, а в ответе k. Ожидаемое время —
O(n + m + k log k): построение множеств, пересечение и сортировка ответа.
Память — O(n + m), включая множества, входные строки и список ответа.
